## Projects

**[Goosedyssey](https://chromewebstore.google.com/detail/goosedessey/jlbdageklahnfedmlblfbmickaajkbha)** — Chrome extension that transforms UWaterloo's exam schedule into something actually readable. Color-coded midterms, finals, reminders. 25+ students use it daily. Some offered to donate. That's the one I'm most proud of.

**[Snowspace](https://github.com/hari495/Snowspace)** — Geospatial analysis tool using Google Earth Engine + Sentinel-2 satellite data. Custom KD-tree over 30k+ coordinates → O(log n) lookup, ~28k ops/sec. Top 5 / 200+ teams at BramHacks. Attracted VC interest.

**[SyncSpace](https://github.com/hari495/SyncSpace)** — Collaborative whiteboard for 30+ concurrent users. Y.js CRDTs over WebSockets, conflict-free real-time sync, 40% memory reduction via Ramer-Douglas-Peucker path simplification.

**[NeuroNotes](https://github.com/hari495/NeuroNotes)** — Multi-stage RAG pipeline with FlashRank re-ranking and HNSW indexing. 10x retrieval precision, <100ms vector search. Local Llama 3.2 via Ollama.
